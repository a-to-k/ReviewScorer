
# Overview ReviewScorer

This project serves as a light RAG architecture incl. an evaluation prompt to legitimize the given score to a new review in comparison to older, similar reviews.

## Requirements

- Using the app requires you to have Ollama downloaded. 

## How To

- Download ReviewScorerApp.zip > unpack it > double click the start.bat 

## Tech Stack

- uv
- Python
- ChromaDB
- llama3
- Hugging Face for embeddings
- LangChain for accessing Ollama
